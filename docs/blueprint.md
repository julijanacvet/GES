# **App Name**: GES Landing

## Core Features:

- Header Component: Sticky header with company logo, navigation links (Residential, Business, Solar Plants, Calculator), language switcher (MK/EN), and a call-to-action button, adapting to both desktop and mobile views.
- Hero Section: Hero section with a headline, sub-headline, placeholder for image/video, and two call-to-action buttons: one to calculate savings and another to request a consultation.
- Key Benefits Section: Section displaying key benefits of solar energy through a series of cards, each featuring an icon, headline, and descriptive text.
- Services Section: Section showcasing different solar services with reusable service cards, including a placeholder image, headline, description, and a call-to-action button.
- Solar Savings Calculator: Interactive solar savings calculator with input fields for current monthly bill, roof size, desired energy offset, and building type. Includes output display for system size, cost, savings, payback period and CO2 reduction. The AI helps act as a tool that determines appropriate parameters to show to the user, depending on user provided data. Has all disclaimers
- FAQ Section: FAQ section with accordion-style questions and answers
- Call To Action: Section for final call to action

## Style Guidelines:

- Primary color: Vibrant green (#28a745) for main actions and highlights, evoking nature and sustainability.
- Background color: Very light green (#f8f9fa) to create a clean and airy feel, ensuring readability.
- Accent color: Yellow (#ffc107) for subtle highlights and attention-grabbing elements, suggesting solar energy and optimism.
- Inter (or similar modern sans-serif) for headings and body text to ensure a clean and modern look.
- Heroicons (or Font Awesome) to offer clear, consistent, and recognizable icons.
- Use max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 container to provide consistent padding and centering.
- Subtle shadow-xl or scale-105 on hover effects for interactive elements.
